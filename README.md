# Draconic

A mobile-first Blox Fruits stock tracker project.

## Current status

The frontend is under development. Live stock data and push notifications are not connected yet. Do not treat displayed stock as live until a verified data source is configured.

## Planned features

- Normal Dealer and Mirage / Advanced Dealer views
- Fruit search and favorites
- Theme customization
- Mobile-friendly installable web app
- Live stock integration when a reliable data source is available

Draconic is an unofficial fan project and is not affiliated with Roblox or the Blox Fruits developers.
